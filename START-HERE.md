# Tallynest — Start Here

The repository is intentionally starting from a clean foundation.

## First objective
Build a legally compliant, production-quality Tallynest product using the permitted Formbricks foundation where appropriate.

## First learning milestones
After the application foundation exists, a developer should be able to run Tallynest locally, understand the repository structure, create a workspace, create and publish a survey/form, submit a response, inspect the response, find the responsible code, make a small UI change, and run relevant tests.

Do not begin rebranding until the core application is operational unless a task explicitly requires branding work.
